Python · Streamlit · scikit-learn · Plotly

Dashboard Cluster Persebaran Pendidik SMA di Indonesia

MASALAH

Bagaimana memetakan disparitas rasio pendidik dan peserta didik antar kabupaten/kota se-Indonesia agar temuan mudah ditelaah pemangku kebijakan?

PROSES

Mengolah 1.529 data SMA (Kemendikdasmen 2025) mengikuti kerangka CRISP-DM: membersihkan 13 baris bernilai Infinity/NaN, membentuk 4 variabel rasio, menstandarkan fitur dengan StandardScaler, lalu K-Means dengan k = 4 dari Elbow Method. Hasilnya disajikan sebagai dashboard Streamlit interaktif dengan profil cluster, radar karakteristik, dan unduhan hasil.

HASIL

Silhouette 0,358 · Davies-Bouldin 0,84 · Calinski-Harabasz 905,9. Cluster 2 (12 wilayah) memiliki rasio pendidik terhadap peserta didik 3,06 — sekitar 7–10 kali cluster lain — dan menjadi temuan utama untuk penelaahan pemerataan pendidik.

Python · TF-IDF · SVM · XGBoost

Klasifikasi Sentimen Ulasan Uber: SVM vs XGBoost

MASALAH

Algoritma mana yang paling akurat mengklasifikasikan opini publik terhadap aplikasi Uber dari teks ulasan bebas?

PROSES

2.000 ulasan (1.456 positif, 492 negatif, 52 netral) diproses dengan text preprocessing dan TF-IDF, lalu dibandingkan SVM vs XGBoost — dengan dan tanpa SMOTE — pada tiga rasio split data.

HASIL

SVM mencapai akurasi terbaik 94%; XGBoost naik dari 91% ke 94% setelah SMOTE pada split 90:10. Dipublikasikan di JITEK Vol. 5 No. 1 (2025).

Sistem Manajemen Pengguna Jaringan MikroTik + RSA Cipher

MASALAH

Bagaimana mengelola pengguna jaringan MikroTik dengan aman tanpa bergantung pada database relasional?

PROSES

Membangun sistem Python berbasis MikroTik API dengan model Waterfall: login admin, penambahan user, profil user, dan bypass device. Data disimpan dalam JSON, pesan diamankan dengan kriptosistem hybrid RSA.

HASIL

Enkripsi dan dekripsi RSA berhasil pada variasi panjang pesan dan kunci. Dipublikasikan di JOCOTIS Vol. 1 No. 4 (Juni 2024) sebagai penulis pertama.
